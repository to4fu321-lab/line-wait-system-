# sql/ — 歴史的資料（新規追加禁止）

このディレクトリのSQLファイルは、マイグレーション管理が整備される前に
Supabase SQL Editor で手動適用されていた時代のスクリプト群です。

**現在のスキーマ変更はすべて `supabase/migrations/` に置いてください。**

- ここにあるファイルは当時の適用記録として残していますが、現在のDBの
  状態を正確に反映している保証はありません（後続のマイグレーションで
  変更されている場合があります）。
- 現在のスキーマを確認したい場合は `types/supabase.ts`（自動生成型）
  または Supabase ダッシュボードを参照してください。
- **新しいSQLをこのディレクトリに追加しないでください。**
