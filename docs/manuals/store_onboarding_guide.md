# 制服販売店向け 導入・操作マニュアル

> 対象: ITに詳しくない店舗スタッフ・オーナー  
> 最終更新: 2026-06-24

---

## このシステムで何ができるか（3分で理解）

| よくある困りごと | このシステムで解決すること |
|---|---|
| 採寸会で行列ができて大混乱 | LINE番号札で自動的に整理番号を発行、呼び出しもLINEで自動 |
| 電話が鳴りやまない | 保護者がLINEで予約・状況確認できるので電話問い合わせが減る |
| 学校ごとのルールをスタッフが覚えられない | 学校マスターに全ルール登録→検索一発で確認 |
| お直しの受け渡し漏れ | 完成したらLINEで自動通知→来店予約 |
| 発注締切を忘れる | 締切3日前に管理画面に赤アラートが表示 |

---

## ▶ はじめにやること（初期設定 5ステップ）

### ステップ1: LINE公式アカウントとの連携

1. **LINEビジネスID**にログインし、LIFF（ライフ）アプリIDを確認する
2. システム管理者から `LIFF_ID`を受け取り、設定ファイルに入力
3. LINE友達登録ボタンのURLをLINE公式アカウントのメニューに設定

> ポイント: この設定は最初の1回だけです。以後は自動で動きます。

---

### ステップ2: 店舗情報の登録

管理画面（`https://your-domain.com/[店舗ID]/admin`）にアクセスします。

1. 初回アクセス時に「PIN番号」を入力（管理者から受け取ったもの）
2. 「営業時間」「店舗名」「お直し案内文」を設定

---

### ステップ3: 学校マスターの登録（最重要）

**ナビゲーション: 下メニュー「案件」→「学校マスター」**

学校ごとに以下を登録します：

| 項目 | 入力内容の例 |
|---|---|
| 学校名 | ○○市立第一中学校 |
| 読み仮名 | マルマルシリツダイイチチュウガッコウ |
| 指定品目 | ブレザー・スラックス・シャツ・校章（必須）、ネクタイ（オプション） |
| サイズ規格 | 標準サイズ表記（Aなど）または学校独自表記 |
| 刺繍仕様 | 名前・学年・位置・文字色 |
| 発注締切日 | 例: 2027-01-20 |
| 引渡し完了目標日 | 例: 2027-03-30 |
| 採寸受付期間 | 例: 2026-11-01 〜 2027-01-31 |

**OCR取込機能（便利機能）**
学校からもらった印刷物をスマホで撮影するだけで、品目リストが自動で登録されます。
操作: 「学校マスター」→「＋新規登録」→「OCRで取込」

> 毎年8〜10月に学校から届く「案内文・チラシ」が来たら、このOCR機能で更新してください。

---

### ステップ4: スタッフLINEアカウントの登録

スタッフが業務通知を受け取れるよう、LINEアカウントをシステムに紐付けます。

1. 管理画面右上「QRコード」ボタン → QRを表示
2. スタッフのスマホLINEアプリで読み取り → 「スタッフとして登録」
3. 以後、受注完了・採寸完了などの通知がLINEに届きます

---

### ステップ5: 動作確認（テスト受付）

1. 管理画面で「テスト追加」ボタンをタップ → テスト用の整理番号が追加される
2. 「呼出」ボタン → 「完了」の順に操作して動きを確認
3. 問題なければ「開店する」ボタンで営業開始

---

## ▶ 日常の操作ガイド

### 【採寸会当日】の使い方

#### 受付開始前
1. 管理画面を開き「開店する」をタップ
2. 繁忙期シーズンダッシュボードで「今日の予約数」を確認
3. 締切アラートがある場合（赤・黄のバッジ）は学校名をタップして内容確認

#### お客様の受け付け
1. お客様がスマホでQRを読み取る → 自動で整理番号がLINEに届く
2. （読み取れない場合）管理画面の「QRコード」ボタンで個別に登録

#### 採寸の進行
1. 待ち画面に名前・学校名・カテゴリが表示される
2. 「採寸開始」ボタン → お客様を呼び出す（LINEに自動で「お呼びしています」通知が届く）
3. 採寸完了後「完了」をタップ

---

### 【お直し・受注管理】の使い方

#### 新規受付
1. 下メニュー「案件」→「＋新規」
2. 顧客名・学校名・加工内容（裾上げ・刺繍など）・サイズ・受け取り方法を入力
3. 「受付する」ボタンで登録完了 → お客様のLINEに受付確認が届く

#### 完成時の連絡
1. 案件一覧で対象を選択
2. 「完成・お渡し可能」ボタンをタップ → お客様LINEに自動通知
3. 来店されたら「お渡し完了」ボタンをタップ

---

### 【年間スケジュール】に合わせた使い方

| 時期 | やること | 使う機能 |
|---|---|---|
| **8〜10月** | 学校マスター更新・新学期対応確認 | 学校マスター（OCR取込） |
| **11月〜** | 採寸予約受付開始 | 予約管理・LINE受付 |
| **12〜1月** | 採寸会の実施 | 整理番号発行・呼び出し |
| **1〜2月** | 発注・締切管理 | 締切アラート・案件タブ |
| **2〜3月** | 入荷・加工・完成連絡 | 案件管理・LINE通知 |
| **4月** | 引渡し集中 | お渡し待ちダッシュボード |
| **5〜6月** | 夏服受付・在校生対応 | CRM履歴検索・追加受注 |

## ▶ 在校生フォロー（永続利用の仕組み）

システムは入学年を記録した生徒に自動的にフォローメッセージを送ります。

### 入学年の登録方法
1. 顧客CRM → 該当お客様の「お子様情報」
2. 「入学年度」欄に入学年（例: 2025）を入力して保存

### 自動通知のスケジュール（例）
| 時期 | 内容 |
|---|---|
| 1年目 5月 | 「夏服の受付が始まりました」 |
| 2年目 4月 | 「進級おめでとうございます。夏服・体操服のご確認を」 |
| 3年目 1月 | 「卒業シーズンです。礼服・スーツのご準備はいかがでしょうか」 |

> 管理画面「フォロー通知設定」から文章のカスタマイズができます。

## ▶ よくあるトラブルと対処法

| 症状 | 原因 | 対処 |
|---|---|---|
| LINEに通知が届かない | LINE友達登録がされていない | QRコードで再登録を案内 |
| 整理番号が飛んでいる | テスト番号を使った | テストデータを削除（管理画面「テスト追加」横の削除ボタン） |
| 学校名が見つからない | マスター未登録 | 「学校マスター」→「＋新規登録」 |
| 締切アラートが消えない | 締切日が過ぎている | 学校マスターの締切日を翌年の日付に更新 |
| 「開店する」ボタンが押せない | 通信エラー | ページをリロードして再試行 |

## ▶ データのバックアップについて

このシステムのデータはすべてクラウド（Supabase）に自動保存されます。
スマホやPCが壊れてもデータは消えません。

**毎年の引き継ぎ時に確認すること**
- [ ] 新年度の学校マスター更新（締切日・採寸期間）
- [ ] 翌年の新入生向け予約枠の開放
- [ ] 卒業した生徒データのアーカイブ（3年後）
