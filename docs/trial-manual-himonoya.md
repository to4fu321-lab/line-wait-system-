# ① 最初のセットアップ（社長・初回だけ）

店舗管理（上のURL・PIN 1234）→ 画面下/横の「**設定**」から行います。

### 1-1. お直しの料金確認（お直し項目・料金）
設定 →「**お直し項目・料金**」
- 裾上げ・ウエスト・丈直しなどの**種類と料金が登録済み**です。実際の店頭価格と合っているか確認・修正してください。
- 種類が足りなければ「標準お直しを取り込む」で一括追加 → 金額だけ直せます。
- サイズ刻みや文字数（ネーム刺繍）も段階生成で素早く作れます。

### 1-2. お直し加工業者（外注先）の登録 ★今回追加
設定 →「**お直し加工業者**」
- お直しを外注する業者を登録します（自社で仕上げる場合は登録不要・受付で「内製」を選択）。
- 例：「○○リフォーム」「△△補正」など。電話番号・メモも残せます。
- 登録すると、**お直し受付の最後でワンタップ選択**できます（毎回入力しなくてOK）。

### 1-3. スタッフ登録（閑散期は社長1名でOK）
設定 →「**スタッフ**」
- まず**社長ご自身を1名登録**（お名前）。
- **PIN（4桁）**を設定しておくと、誰が受付・対応したかを記録できます（閑散期は省略可）。
- ※繁忙期のアルバイトは「③」でまとめて登録します。

> スタッフのPINは、この「スタッフ」画面でいつでも一覧確認できます（会社まとめ画面の各店舗カード「スタッフPIN」からも確認可）。

# ② 日々の使い方（閑散期・社長1人運用）

社長1人のときは**シンプルに**。順番待ちは混まなければ無理に使わず、まずは**お直し受付と予約**を中心に慣れてください。

## お直し（受付 → お渡し）
1. 案件タブ →「**お直し 新規受付**」
2. 案内に沿って入力：**お客様 → 品目・内容 → 仕上がり希望日**
   - お客様は**電話番号だけでも新規登録**できます
   - 金額は料金マスタから**自動計算**
3. 最後に **加工業者**を選択（自社なら「内製」）／社内メモ → 受付完了
4. 仕上がったら「**完了**」、お客様が受け取ったら「**お渡し**」

#### 📷 メモしか無い・急ぎのとき
受付画面の「**メモ読取**」で手書きメモや伝票を撮影 → 内容・お名前が自動入力されます（精度が中/低のときは確認を）。

## 予約
1. 予約タブ →「**新規予約**」
2. お客様・**希望日時**・用件を登録
3. 当日は予約一覧で確認 → 対応 → 完了

## 順番待ち（混雑時のみ）
- 受付タブで「**受付**」→ お名前/人数で番号発行 →「**呼び出し**」→「**完了**」
- 閑散期は使わなくてもOK。**操作の練習**として時々使うと繁忙期に慌てません。

## 顧客
- お名前・電話番号で**検索**、受付時に**紐付け**。次回からスムーズです。

# ③ 繁忙期の増員対応（アルバイト3名）

繁忙期に入る前に、ここだけ準備すれば切り替えられます。

### 3-1. アルバイトをスタッフ登録
設定 →「**スタッフ**」→ アルバイト3名を追加
- それぞれに**PIN（4桁）**を設定（例：本人の覚えやすい番号）
- PIN一覧はこの画面でいつでも確認できます

### 3-2. 受付・対応の記録
- 受付や対応のときに**担当スタッフ**を選べるので、誰が受けたか後から分かります
- お直しの**対応者**も記録でき、引き継ぎがラクになります

### 3-3. 順番待ちをフル活用
- 来店が増えたら順番待ちが本領発揮。**呼び出し**でお客様を待たせず回せます
- LINE連携済みのお客様には呼び出し通知も送れます

### 3-4. 繁忙期が終わったら
- アルバイトのスタッフは「**非表示**」にすれば一覧から隠せます（データは残ります）。翌シーズンは再表示でOK。

## こまったとき Q&A

| 症状 | 対処 |
|---|---|
| ネットが不安定／画面が出ない | **紙運用に切替**。落ち着いたら後で入力 |
| PINを忘れた | 設定→スタッフ で確認。店舗PINは社長が管理 |
| 入力を間違えた | 各案件・顧客は**編集**で修正可。完了/お渡しも戻せます |
| お客様がLINE未連携 | 口頭・番号表示・お電話で対応（通知は任意） |
| 同じお客様が二重登録 | 顧客検索で確認し1件に統一 |
| 外注先が一覧に出ない | 設定→お直し加工業者 で登録（登録前は手入力欄になります）|

## トライアルで見るポイント（社長用メモ）

閑散期（1人運用）でまず確認：
- お直し受付が**紙より速い／楽**か（入力時間・記入漏れ）
- 仕上がり予定・お渡しの管理がしやすいか
- メモ写真OCRが実用に足りるか

繁忙期に向けて：
- アルバイトが**説明なしで受付**できるか（PINログイン→受付の分かりやすさ）
- 順番待ちで待ち時間・取りこぼしが減るか

> これらが「紙より良い」と感じられたら本採用。発注・入荷・レジ等は必要に応じて段階追加します。
