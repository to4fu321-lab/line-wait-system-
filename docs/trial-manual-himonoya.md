対象範囲：**順番待ち / お直し / 予約 / 顧客管理** の4機能

## 2. 順番待ち（受付）

混雑時にお客様の順番を管理します。**一番かんたんなので、まずここから慣れる**のがおすすめ。

### 受付する
1. ダッシュボード／受付タブで「**受付**（新規）」
2. お客様の**お名前**（または人数・用件）を入力して登録 → 番号が発行されます

### 呼び出し・完了
- 順番が来たら「**呼び出し**」→ 接客開始したら「**完了**」
- LINE連携済みのお客様には呼び出し通知が飛びます（未連携なら口頭・番号表示で対応）

### 来ない・キャンセル
- 呼んでも来ない場合は「**キャンセル**」または後回し。後で戻ってきたら再受付でOK

> 📌 トライアルの見どころ：**平均待ち時間**と**呼んでも来ない率**。紙より楽になったか。

## 3. お直し（受付 → お渡し）

学生服・スーツ・婦人服のお直し（裾上げ・ウエスト詰め／出し・袖丈・着丈直し 等）を管理します。

### 新規受付（ウィザード）
1. 案件タブ →「**お直し 新規受付**」
2. 画面の案内に沿って 1項目ずつ入力
   - **お客様**（電話番号で新規登録も可）
   - **品目・お直し内容**（例：学生服スラックスの裾上げ、スーツのウエスト詰め、スカート丈直し）
   - **仕上がり希望日**
3. 料金は**料金マスタ**から自動計算（裾上げ・ウエスト等の単価は登録済み）

#### 📷 メモしか無い／急ぎのとき（写真OCR）
- 受付ウィザードのヘッダー「**メモ読取**」で、手書きメモや伝票を**撮影 → 自動でデータ化**
- 読み取り後に内容・お客様名を確認・修正して保存（精度が「中／低」のときは特に確認を）

### 完了 → お渡し
- 仕上がったら案件を「**完了**」
- お客様が受け取りに来たら「**お渡し**」で締め
- 完了時にLINE通知（連携客）で「お直しできました」を送れます

### 料金マスタの見方
- 設定 → お直しマスタ で、服種・項目・サイズ別の単価を確認・調整できます
- 実際の店頭価格と差があれば、店長が見直してください

> 📌 見どころ：**受付〜お渡しのリードタイム**、**記入漏れ・聞き漏れの減少**、**入力にかかる時間**（紙比）。

## 4. 予約

採寸・来店の予約を受けて、繁忙日の混雑を分散します。

1. 予約タブ →「**新規予約**」
2. お客様・**希望日時**・用件を登録
3. 当日：予約一覧で来店を確認 → 接客 → 完了

> 📌 見どころ：予約経由の来店がスムーズか、ピーク時間が平準化できるか。

---

## 5. 顧客管理

お直し・予約・順番待ちと**お客様をひも付け**ると、再来店時にスムーズです。

- **検索**：お名前・電話番号で検索
- **紐付け**：受付時に既存のお客様を選んで紐付け
- **新規登録**：電話番号だけでもその場で登録可能（お名前＋電話番号）

> 学生服は「保護者＋お子様（学校・学年）」の形で残せます。スーツ・婦人服は本人のお客様情報で。

## 6. こまったとき Q&A

| 症状 | 対処 |
|---|---|
| ネットが不安定／画面が出ない | **紙運用に切替**。落ち着いたら後でアプリに入力 |
| PINを忘れた | 店長へ。総管理（/super-admin）で確認・変更できます |
| 入力を間違えた | 各案件・顧客は**編集**で修正可能。完了/お渡しも戻せます |
| お客様がLINE未連携 | 口頭・番号表示・お電話で対応（通知は任意機能） |
| 同じお客様が二重登録された | 顧客検索で確認し、片方に統一（迷ったら店長へ） |

## 7. トライアル中に見るKPI（店長用）

2週間ごとに、紙運用と比べてどうかを確認します。

- **順番待ち**：平均待ち時間／呼んでも来ない率／1日の処理組数
- **お直し**：受付〜お渡しのリードタイム／受付1件の入力時間／記入漏れの件数
- **予約**：予約経由来店率／ピーク時間の平準化
- **スタッフ所感**：「紙に戻りたいか？」（5段階）＋ 使いにくかった点メモ

> この数値が「紙より良い」と言えたら、本採用＆機能追加（発注・入荷・OCR常用・セルフ入力・完了SMS等）へ進みます。
